# TO-DO APP

A lightweight, browser-based to-do list for quickly adding and removing tasks.

## Features

- Add tasks using the input field
- Remove individual tasks with the delete button
- Simple interface styled with CSS
- Runs entirely in the browser with no dependencies

## Built with

- HTML
- CSS
- JavaScript

## Run locally

1. Clone the repository.
2. Open `index.html` in a modern web browser.
3. Enter a task and select **Add Task**. Use **delete** beside a task to remove it.

## Project structure

- `index.html` — application markup
- `style.css` — application styling
- `app.js` — task creation and deletion logic
